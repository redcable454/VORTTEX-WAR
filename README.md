# VORTTEX WAR

Videojuego original de acción y plataformas **cartoon 2D**, preparado para navegador y futura adaptación Android.

## Estado actual
Prototipo web inicial (v0.1.0):
- Lobby de inicio y paneles de misiones, tienda, ruleta, amigos y personajes.
- Nivel de entrenamiento 2D con movimiento, salto, disparo, enemigos, monedas y meta.
- Controles de teclado y botones táctiles.
- Diseño adaptable a móviles y escritorio.

## Ejecutar
Abre `index.html` en un navegador moderno o publica el repositorio con GitHub Pages.

## Controles
- Mover: A/D o flechas izquierda/derecha.
- Saltar: Espacio, flecha arriba o W.
- Disparar: Z.
- Pausa: Escape.
- En móvil: botones en pantalla.

## Publicar con GitHub Pages
En el repositorio: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
